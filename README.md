# 👑 BlackCrown Barbershop Website

Website profil profesional dan sistem booking online untuk **BlackCrown Barbershop**. Dirancang dengan estetika modern-minimalis, fitur *dark mode*, dan integrasi langsung ke WhatsApp untuk pemesanan layanan.

---

## ✨ Fitur Utama

*   **Premium UI/UX**: Desain mewah dengan efek *Glassmorphism* dan animasi *Fade-in* saat scroll.
*   **Dual Theme**: Mendukung mode Gelap (Dark) dan Terang (Light).
*   **Online Booking**: Formulir pemesanan jadwal yang terintegrasi otomatis dengan WhatsApp.
*   **Responsive Design**: Tampilan optimal di berbagai perangkat (HP, Tablet, Desktop).
*   **Interactive Gallery**: Showcase hasil potongan rambut terbaik.
*   **Google Maps Integration**: Memudahkan pelanggan menemukan lokasi barbershop.
*   **Background Music**: Menambah atmosfer eksklusif saat menjelajahi website.

---

## 🚀 Teknologi yang Digunakan

*   **HTML5**: Struktur konten semantik.
*   **CSS3**: Styling kustom menggunakan CSS Variables untuk manajemen tema.
*   **JavaScript (Vanilla)**: Logika interaktif, slider testimoni, dan integrasi WhatsApp.
*   **Google Fonts**: Menggunakan font 'Poppins' untuk kesan modern dan bersih.
